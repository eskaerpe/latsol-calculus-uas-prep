1.1 Integral dengan Substitusi Kompleks

Soal 1.1

Hitung integral berikut:

\[\int_0^1 \frac{x+2}{(x^2+4x+1)^2} \, dx\]
Strategi: Penyebut berbentuk polinomial kuadrat yang dipangkatkan. Gunakan substitusi \(u = x^2 + 4x + 1\) sehingga turunannya \(du = (2x+4)\,dx = 2(x+2)\,dx\) muncul di pembilang.
Penyelesaian

Langkah 1: Misalkan

\[u = x^2 + 4x + 1 \quad\Rightarrow\quad du = (2x+4)\,dx = 2(x+2)\,dx\]

Sehingga \((x+2)\,dx = \dfrac{du}{2}\).

Langkah 2: Ubah batas integral.

\[ x = 0 \;\Rightarrow\; u = 0^2 + 4(0) + 1 = 1 \qquad x = 1 \;\Rightarrow\; u = 1^2 + 4(1) + 1 = 6 \]

Langkah 3: Substitusikan ke dalam integral.

\[ \int_0^1 \frac{x+2}{(x^2+4x+1)^2}\,dx = \int_1^6 \frac{1}{u^2}\cdot\frac{du}{2} = \frac12 \int_1^6 u^{-2}\,du \]

Langkah 4: Hitung integral.

\[ \frac12 \left[ \frac{u^{-1}}{-1} \right]_1^6 = -\frac12 \left[ \frac{1}{u} \right]_1^6 = -\frac12 \left( \frac16 - 1 \right) = -\frac12 \left( -\frac56 \right) = \frac{5}{12} \]
\[ \boxed{\int_0^1 \frac{x+2}{(x^2+4x+1)^2}\,dx = \frac{5}{12}} \]

1.2 Integral Fungsi Komposit

Soal 1.2

Hitung integral berikut:

\[\int \frac{(\sqrt{x}+4)^2}{\sqrt{x}} \, dx\]
Strategi: Ekspansikan pembilang terlebih dahulu, lalu bagi setiap suku dengan \(\sqrt{x}\) dan integrasikan menggunakan aturan pangkat.
Penyelesaian

Langkah 1: Ekspansikan \((\sqrt{x}+4)^2\).

\[ (\sqrt{x}+4)^2 = (\sqrt{x})^2 + 2\cdot\sqrt{x}\cdot4 + 4^2 = x + 8\sqrt{x} + 16 \]

Langkah 2: Bagi dengan \(\sqrt{x}\).

\[ \frac{(\sqrt{x}+4)^2}{\sqrt{x}} = \frac{x}{\sqrt{x}} + \frac{8\sqrt{x}}{\sqrt{x}} + \frac{16}{\sqrt{x}} = x^{1/2} + 8 + 16x^{-1/2} \]

Langkah 3: Integrasikan suku demi suku.

\[ \begin{aligned} \int x^{1/2}\,dx &= \frac{2}{3}x^{3/2} \\[4pt] \int 8\,dx &= 8x \\[4pt] \int 16x^{-1/2}\,dx &= 16\cdot\frac{x^{1/2}}{1/2} = 32x^{1/2} \end{aligned} \]

Langkah 4: Jumlahkan semua hasil.

\[ \int \frac{(\sqrt{x}+4)^2}{\sqrt{x}}\,dx = \frac{2}{3}x^{3/2} + 8x + 32\sqrt{x} + C \]
\[ \boxed{\int \frac{(\sqrt{x}+4)^2}{\sqrt{x}}\,dx = \frac{2}{3}x^{3/2} + 8x + 32\sqrt{x} + C} \]

1.3 Integral Eksponensial dengan Trigonometri

Soal 1.3

Hitung integral berikut:

\[\int e^x \sin x \, dx\]
Strategi: Integral bentuk \(e^{ax}\sin(bx)\) atau \(e^{ax}\cos(bx)\) diselesaikan dengan integrasi parsial berulang sebanyak dua kali sehingga muncul kembali bentuk integral semula, lalu selesaikan secara aljabar (metode reduksi).
Penyelesaian

Langkah 1: Misalkan \(I = \displaystyle\int e^x \sin x \, dx\). Lakukan parsial pertama.

\[ \begin{aligned} u &= \sin x &\quad dv &= e^x\,dx \\ du &= \cos x\,dx &\quad v &= e^x \end{aligned} \]
\[ I = e^x \sin x - \int e^x \cos x \, dx \]

Langkah 2: Lakukan parsial kedua pada \(\int e^x \cos x \, dx\).

\[ \begin{aligned} u &= \cos x &\quad dv &= e^x\,dx \\ du &= -\sin x\,dx &\quad v &= e^x \end{aligned} \]
\[ \int e^x \cos x \, dx = e^x \cos x + \int e^x \sin x \, dx = e^x \cos x + I \]

Langkah 3: Substitusikan kembali.

\[ I = e^x \sin x - (e^x \cos x + I) = e^x \sin x - e^x \cos x - I \]
\[ 2I = e^x(\sin x - \cos x) \quad\Rightarrow\quad I = \frac{e^x}{2}(\sin x - \cos x) + C \]
\[ \boxed{\int e^x \sin x \, dx = \frac{e^x}{2}(\sin x - \cos x) + C} \]

1.4 Integral dengan Substitusi Radikal

Soal 1.4

Hitung integral berikut:

\[\int x^5\sqrt[3]{x^3 + 4} \, dx\]
Strategi: Bentuk \(\sqrt[3]{x^3+4}\) menyarankan substitusi \(u = x^3+4\). Turunannya \(du = 3x^2\,dx\) dan sisa \(x^5 = x^3\cdot x^2 = (u-4)x^2\) dapat dimanfaatkan.
Penyelesaian

Langkah 1: Misalkan

\[ u = x^3 + 4 \quad\Rightarrow\quad du = 3x^2\,dx \quad\Rightarrow\quad x^2\,dx = \frac{du}{3} \]

Langkah 2: Nyatakan \(x^5\) dalam \(u\).

\[ x^5 = x^3 \cdot x^2 = (u-4) \cdot x^2 \]

Langkah 3: Substitusikan seluruhnya.

\[ \begin{aligned} \int x^5 (x^3+4)^{1/3}\,dx &= \int (u-4) \, u^{1/3} \cdot \frac{du}{3} \\[4pt] &= \frac13 \int (u^{4/3} - 4u^{1/3})\,du \end{aligned} \]

Langkah 4: Integrasikan.

\[ \begin{aligned} \frac13 \int u^{4/3}\,du &= \frac13 \cdot \frac{u^{7/3}}{7/3} = \frac13 \cdot \frac{3}{7} u^{7/3} = \frac{1}{7}u^{7/3} \\[4pt] \frac13 \int (-4u^{1/3})\,du &= -\frac{4}{3} \cdot \frac{u^{4/3}}{4/3} = -\frac{4}{3} \cdot \frac{3}{4} u^{4/3} = -u^{4/3} \end{aligned} \]
\[ \frac13 \int (u^{4/3} - 4u^{1/3})\,du = \frac{1}{7}u^{7/3} - u^{4/3} + C \]

Langkah 5: Kembalikan ke variabel \(x\).

\[ \int x^5\sqrt[3]{x^3+4}\,dx = \frac{1}{7}(x^3+4)^{7/3} - (x^3+4)^{4/3} + C \]
\[ \boxed{\int x^5\sqrt[3]{x^3+4}\,dx = \frac{1}{7}(x^3+4)^{7/3} - (x^3+4)^{4/3} + C} \]

1.5 Integral Trigonometri Kompleks

Soal 1.5

Hitung integral berikut:

\[\int \frac{\sin(4x-1)}{1-\sin^2(4x-1)} \, dx\]
Strategi: Gunakan identitas trigonometri \(1 - \sin^2\theta = \cos^2\theta\), lalu sederhanakan menjadi bentuk \(\tan\theta\sec\theta\) yang integralnya adalah \(\sec\theta\).
Penyelesaian

Langkah 1: Gunakan identitas \(1 - \sin^2(4x-1) = \cos^2(4x-1)\).

\[ \frac{\sin(4x-1)}{1-\sin^2(4x-1)} = \frac{\sin(4x-1)}{\cos^2(4x-1)} = \tan(4x-1)\sec(4x-1) \]

Langkah 2: Substitusi linear \(u = 4x-1\) sehingga \(du = 4\,dx\).

\[ \int \frac{\sin(4x-1)}{1-\sin^2(4x-1)}\,dx = \int \tan u \sec u \cdot \frac{du}{4} = \frac14 \int \tan u \sec u \, du \]

Langkah 3: Ingat bahwa \(\displaystyle\frac{d}{du}(\sec u) = \sec u \tan u\).

\[ \frac14 \int \tan u \sec u \, du = \frac14 \sec u + C \]

Langkah 4: Kembalikan ke \(x\).

\[ \frac14 \sec(4x-1) + C \]
\[ \boxed{\int \frac{\sin(4x-1)}{1-\sin^2(4x-1)}\,dx = \frac14 \sec(4x-1) + C} \]

1.6 Integral Parsial dan Logaritma

Soal 1.6

Hitung integral berikut:

\[\int \sqrt{x} \ln x \, dx\]
Strategi: Integral hasil kali fungsi logaritma dan fungsi pangkat diselesaikan dengan integrasi parsial. Pilih \(u = \ln x\) karena turunannya lebih sederhana, dan \(dv = \sqrt{x}\,dx\) karena mudah diintegralkan.
Penyelesaian

Langkah 1: Tulis \(\sqrt{x} = x^{1/2}\). Gunakan integrasi parsial.

\[ \begin{aligned} u &= \ln x &\quad dv &= x^{1/2}\,dx \\[4pt] du &= \frac{1}{x}\,dx &\quad v &= \frac{2}{3}x^{3/2} \end{aligned} \]

Langkah 2: Terapkan rumus \(\int u\,dv = uv - \int v\,du\).

\[ \begin{aligned} \int x^{1/2}\ln x \, dx &= \frac{2}{3}x^{3/2}\ln x - \int \frac{2}{3}x^{3/2}\cdot\frac{1}{x}\,dx \\[4pt] &= \frac{2}{3}x^{3/2}\ln x - \frac{2}{3}\int x^{1/2}\,dx \end{aligned} \]

Langkah 3: Selesaikan sisa integral.

\[ \frac{2}{3}\int x^{1/2}\,dx = \frac{2}{3}\cdot\frac{2}{3}x^{3/2} = \frac{4}{9}x^{3/2} \]
\[ \int \sqrt{x}\ln x \, dx = \frac{2}{3}x^{3/2}\ln x - \frac{4}{9}x^{3/2} + C \]

Langkah 4 (opsional): Faktorkan \(\frac{2}{9}x^{3/2}\) untuk bentuk yang lebih ringkas.

\[ \frac{2}{9}x^{3/2}(3\ln x - 2) + C \]
\[ \boxed{\int \sqrt{x} \ln x \, dx = \frac{2}{3}x^{3/2}\ln x - \frac{4}{9}x^{3/2} + C} \]

1.7 Integral dengan Batas dan Hiperbola

Soal 1.7

Hitung integral berikut:

\[\int_0^{\pi} \cos x \sinh x \, dx\]
Strategi: Integral hasil kali fungsi trigonometri dan hiperbola mirip dengan bentuk \(e^{ax}\sin(bx)\), dapat diselesaikan dengan integrasi parsial berulang (metode reduksi).
Penyelesaian

Langkah 1: Misalkan \(I = \int \cos x \sinh x \, dx\). Lakukan parsial pertama.

\[ \begin{aligned} u &= \cos x &\quad dv &= \sinh x\,dx \\ du &= -\sin x\,dx &\quad v &= \cosh x \end{aligned} \]
\[ I = \cos x \cosh x + \int \sin x \cosh x \, dx \]

Langkah 2: Parsial kedua pada \(\int \sin x \cosh x \, dx\).

\[ \begin{aligned} u &= \sin x &\quad dv &= \cosh x\,dx \\ du &= \cos x\,dx &\quad v &= \sinh x \end{aligned} \]
\[ \int \sin x \cosh x \, dx = \sin x \sinh x - \int \cos x \sinh x \, dx = \sin x \sinh x - I \]

Langkah 3: Substitusikan kembali.

\[ I = \cos x \cosh x + \sin x \sinh x - I \;\Longrightarrow\; 2I = \cos x \cosh x + \sin x \sinh x \]
\[ I = \frac{1}{2}(\cos x \cosh x + \sin x \sinh x) \]

Langkah 4: Hitung integral tentu.

\[ \begin{aligned} \int_0^{\pi} \cos x \sinh x \, dx &= \frac12\Big[ \cos x \cosh x + \sin x \sinh x \Big]_0^{\pi} \\[4pt] &= \frac12\big[ (\cos\pi \cosh\pi + \sin\pi \sinh\pi) - (\cos0 \cosh0 + \sin0 \sinh0) \big] \\[4pt] &= \frac12\big[ (-1\cdot\cosh\pi + 0) - (1\cdot1 + 0) \big] \\[4pt] &= \frac12(-\cosh\pi - 1) = -\frac{1}{2}(\cosh\pi + 1) \end{aligned} \]
\[ \boxed{\int_0^{\pi} \cos x \sinh x \, dx = -\frac{1}{2}(\cosh\pi + 1)} \]

1.8 Integral Trigonometri Berpangkat

Soal 1.8

Hitung integral berikut:

\[\int_0^{\pi/2} \cos^5\theta \, d\theta\]
Strategi: Untuk \(\cos^n x\) dengan \(n\) ganjil, pisahkan satu faktor \(\cos x\) untuk substitusi \(u = \sin x\), lalu nyatakan sisa \(\cos^{n-1}x\) dalam \(\sin x\) via \(\cos^2 x = 1 - \sin^2 x\).
Penyelesaian

Langkah 1: Pisahkan \(\cos^5\theta = \cos^4\theta \cdot \cos\theta\).

\[ \cos^5\theta = (1 - \sin^2\theta)^2 \cos\theta \]

Langkah 2: Substitusi \(u = \sin\theta\) sehingga \(du = \cos\theta\,d\theta\).

\[ \theta=0 \Rightarrow u=0 \qquad \theta=\frac{\pi}{2} \Rightarrow u=1 \]
\[ \int_0^{\pi/2} \cos^5\theta\,d\theta = \int_0^1 (1 - u^2)^2 \, du \]

Langkah 3: Ekspansikan \((1 - u^2)^2\).

\[ (1 - u^2)^2 = 1 - 2u^2 + u^4 \]

Langkah 4: Integrasikan.

\[ \int_0^1 (1 - 2u^2 + u^4)\,du = \left[ u - \frac{2}{3}u^3 + \frac{1}{5}u^5 \right]_0^1 = 1 - \frac{2}{3} + \frac{1}{5} \]

Langkah 5: Sederhanakan.

\[ 1 - \frac{2}{3} + \frac{1}{5} = \frac{15 - 10 + 3}{15} = \frac{8}{15} \]
\[ \boxed{\int_0^{\pi/2} \cos^5\theta \, d\theta = \frac{8}{15}} \]

1.9 Integral Trigonometri Bentuk \(\sin^m \cos^n\)

Soal 1.9

Hitung integral berikut:

\[\int \sin^5 4x \cos^2 4x \, dx\]
Strategi: Karena pangkat \(\sin\) ganjil (\(m = 5\)), substitusi \(u = \cos 4x\) menjadi pilihan tepat. Pisahkan satu faktor \(\sin 4x\) untuk \(du\) dan nyatakan sisa \(\sin^4 4x\) dalam \(\cos 4x\).
Penyelesaian

Langkah 1: Misalkan \(u = \cos 4x\), maka \(du = -4\sin 4x\,dx\).

\[ \sin 4x\,dx = -\frac{du}{4} \]

Langkah 2: Nyatakan \(\sin^5 4x\) dalam \(u\).

\[ \sin^5 4x = \sin^4 4x \cdot \sin 4x = (1 - \cos^2 4x)^2 \cdot \sin 4x = (1 - u^2)^2 \cdot \sin 4x \]

Langkah 3: Substitusikan semuanya.

\[ \begin{aligned} \int \sin^5 4x \cos^2 4x \, dx &= \int (1 - u^2)^2 \cdot u^2 \cdot \left(-\frac{du}{4}\right) \\[4pt] &= -\frac14 \int u^2 (1 - 2u^2 + u^4)\,du \\[4pt] &= -\frac14 \int (u^2 - 2u^4 + u^6)\,du \end{aligned} \]

Langkah 4: Integrasikan.

\[ -\frac14 \left( \frac{u^3}{3} - \frac{2u^5}{5} + \frac{u^7}{7} \right) + C \]

Langkah 5: Kembalikan \(u = \cos 4x\).

\[ \int \sin^5 4x \cos^2 4x \, dx = -\frac{1}{12}\cos^3 4x + \frac{1}{10}\cos^5 4x - \frac{1}{28}\cos^7 4x + C \]
\[ \boxed{\int \sin^5 4x \cos^2 4x \, dx = -\frac{1}{12}\cos^3 4x + \frac{1}{10}\cos^5 4x - \frac{1}{28}\cos^7 4x + C} \]

1.10 Integral Substitusi Trigonometri (Bentuk \(\sqrt{a^2+x^2}\))

Soal 1.10

Hitung integral berikut:

\[\int \frac{1}{\sqrt{9+x^2}} \, dx\]
Strategi: Bentuk \(\sqrt{a^2 + x^2}\) diselesaikan dengan substitusi \(x = a\tan\theta\). Untuk \(a = 3\), gunakan \(x = 3\tan\theta\) sehingga \(\sqrt{9+x^2} = 3\sec\theta\) dan \(dx = 3\sec^2\theta\,d\theta\). Hasil integralnya adalah \(\ln|x + \sqrt{a^2+x^2}| + C\).
Penyelesaian (Metode Substitusi Trigonometri)

Langkah 1: Misalkan \(x = 3\tan\theta\) dengan \(-\frac{\pi}{2} < \theta < \frac{\pi}{2}\).

\[ dx = 3\sec^2\theta\,d\theta \qquad \sqrt{9+x^2} = \sqrt{9+9\tan^2\theta} = 3\sqrt{1+\tan^2\theta} = 3\sec\theta \]

Langkah 2: Substitusikan.

\[ \int \frac{1}{\sqrt{9+x^2}}\,dx = \int \frac{1}{3\sec\theta} \cdot 3\sec^2\theta\,d\theta = \int \sec\theta\,d\theta \]

Langkah 3: Integral dari \(\sec\theta\) adalah \(\ln|\sec\theta + \tan\theta| + C\).

\[ \int \sec\theta\,d\theta = \ln|\sec\theta + \tan\theta| + C \]

Langkah 4: Kembalikan ke \(x\). Dari \(x = 3\tan\theta\):

\[ \tan\theta = \frac{x}{3}, \qquad \sec\theta = \sqrt{1+\tan^2\theta} = \sqrt{1 + \frac{x^2}{9}} = \frac{\sqrt{9+x^2}}{3} \]
\[ \begin{aligned} \ln|\sec\theta + \tan\theta| + C &= \ln\left|\frac{\sqrt{9+x^2}}{3} + \frac{x}{3}\right| + C \\[4pt] &= \ln\left|\frac{x + \sqrt{9+x^2}}{3}\right| + C \\[4pt] &= \ln|x + \sqrt{9+x^2}| - \ln 3 + C \\[4pt] &= \ln|x + \sqrt{9+x^2}| + C' \end{aligned} \]
\[ \boxed{\int \frac{1}{\sqrt{9+x^2}}\,dx = \ln\left|x + \sqrt{9+x^2}\right| + C} \]

1.11 Integral Substitusi Trigonometri (Bentuk \(\sqrt{a^2-x^2}\))

Soal 1.11

Hitung integral berikut:

\[\int \frac{\sqrt{4-x^2}}{x} \, dx\]
Strategi: Bentuk \(\sqrt{a^2 - x^2}\) dengan \(a = 2\) diselesaikan menggunakan substitusi \(x = a\sin\theta = 2\sin\theta\). Setelah substitusi, sederhanakan menjadi integral fungsi trigonometri yang melibatkan \(\csc\theta\) dan \(\sin\theta\).
Penyelesaian

Langkah 1: Misalkan \(x = 2\sin\theta\) dengan \(-\frac{\pi}{2} \le \theta \le \frac{\pi}{2}\), \(\theta \neq 0\).

\[ dx = 2\cos\theta\,d\theta \qquad \sqrt{4-x^2} = \sqrt{4-4\sin^2\theta} = 2\sqrt{1-\sin^2\theta} = 2\cos\theta \]

Langkah 2: Substitusikan.

\[ \int \frac{\sqrt{4-x^2}}{x}\,dx = \int \frac{2\cos\theta}{2\sin\theta} \cdot 2\cos\theta\,d\theta = 2 \int \frac{\cos^2\theta}{\sin\theta}\,d\theta \]

Langkah 3: Gunakan \(\cos^2\theta = 1 - \sin^2\theta\).

\[ 2 \int \frac{1 - \sin^2\theta}{\sin\theta}\,d\theta = 2 \int (\csc\theta - \sin\theta)\,d\theta \]

Langkah 4: Integrasikan.

\[ 2\left( -\ln|\csc\theta + \cot\theta| + \cos\theta \right) + C \]

Langkah 5: Kembalikan ke \(x\). Dari \(x = 2\sin\theta\):

\[ \sin\theta = \frac{x}{2},\quad \cos\theta = \frac{\sqrt{4-x^2}}{2},\quad \csc\theta = \frac{2}{x},\quad \cot\theta = \frac{\sqrt{4-x^2}}{x} \]
\[ \begin{aligned} \int \frac{\sqrt{4-x^2}}{x}\,dx &= -2\ln\left|\frac{2}{x} + \frac{\sqrt{4-x^2}}{x}\right| + 2\cdot\frac{\sqrt{4-x^2}}{2} + C \\[4pt] &= -2\ln\left|\frac{2 + \sqrt{4-x^2}}{x}\right| + \sqrt{4-x^2} + C \end{aligned} \]
\[ \boxed{\int \frac{\sqrt{4-x^2}}{x}\,dx = -2\ln\left|\frac{2 + \sqrt{4-x^2}}{x}\right| + \sqrt{4-x^2} + C} \]

3.1 Limit Comparison Test LCT

Soal 3.1
\[\sum_{n=2}^{\infty} \frac{\ln^2 n}{n}\]
Strategi: Bandingkan dengan deret harmonik \(\sum 1/n\) (divergen) menggunakan Limit Comparison Test.
Penyelesaian

Ambil \(a_n = \dfrac{\ln^2 n}{n}\) dan \(b_n = \dfrac{1}{n}\).

\[\lim_{n\to\infty} \frac{a_n}{b_n} = \lim_{n\to\infty} \frac{\ln^2 n / n}{1/n} = \lim_{n\to\infty} \ln^2 n = \infty\]

Karena limit \(\infty\) dan \(\sum b_n\) divergen, maka \(\sum a_n\) divergen.

\[\boxed{\text{Divergen}}\]

3.2 Ratio Test (Eksponensial) Ratio Test

Soal 3.2
\[\sum_{k=1}^{\infty} \frac{k^2}{e^k} = \sum_{k=1}^{\infty} k^2 e^{-k}\]
Penyelesaian

Gunakan Ratio Test dengan \(a_k = k^2 e^{-k}\).

\[\lim_{k\to\infty} \frac{a_{k+1}}{a_k} = \lim_{k\to\infty} \frac{(k+1)^2 e^{-(k+1)}}{k^2 e^{-k}} = \lim_{k\to\infty} \left(\frac{k+1}{k}\right)^2 \cdot e^{-1} = \frac{1}{e} < 1\]

Karena limitnya \(1/e < 1\), deret konvergen.

\[\boxed{\text{Konvergen}}\]

3.3 Ratio Test (Eksponensial Kuadrat) Ratio Test

Soal 3.3
\[\sum_{k=1}^{\infty} \frac{k}{e^{k^2}} = \sum_{k=1}^{\infty} k e^{-k^2}\]
Penyelesaian

Gunakan Ratio Test dengan \(a_k = k e^{-k^2}\).

\[\lim_{k\to\infty} \frac{a_{k+1}}{a_k} = \lim_{k\to\infty} \frac{(k+1) e^{-(k+1)^2}}{k e^{-k^2}} = \lim_{k\to\infty} \left(1+\frac1k\right) e^{-2k-1} = 0 < 1\]

Karena limitnya \(0 < 1\), deret konvergen.

\[\boxed{\text{Konvergen}}\]

3.4 Ratio Test (Faktorial) Ratio Test

Soal 3.4
\[\sum_{n=1}^{\infty} \frac{2^n}{n!}\]
Penyelesaian

Gunakan Ratio Test dengan \(a_n = \dfrac{2^n}{n!}\).

\[\lim_{n\to\infty} \frac{a_{n+1}}{a_n} = \lim_{n\to\infty} \frac{2^{n+1}/(n+1)!}{2^n/n!} = \lim_{n\to\infty} \frac{2}{n+1} = 0 < 1\]

Karena limitnya \(0 < 1\), deret konvergen.

\[\boxed{\text{Konvergen}}\]

3.5 Ratio Test (Faktorial Pembilang) Ratio Test

Soal 3.5
\[\sum_{n=1}^{\infty} \frac{n!}{n^{100}}\]
Penyelesaian

Gunakan Ratio Test dengan \(a_n = \dfrac{n!}{n^{100}}\).

\[\lim_{n\to\infty} \frac{a_{n+1}}{a_n} = \lim_{n\to\infty} \frac{(n+1)!/(n+1)^{100}}{n!/n^{100}} = \lim_{n\to\infty} (n+1)\left(\frac{n}{n+1}\right)^{100} = \infty > 1\]

Karena limitnya \(\infty > 1\), deret divergen.

\[\boxed{\text{Divergen}}\]

3.6 Ratio Test (Faktorial Genap) Ratio Test

Soal 3.6
\[\sum_{n=1}^{\infty} \frac{n^3}{(2n)!}\]
Penyelesaian

Gunakan Ratio Test dengan \(a_n = \dfrac{n^3}{(2n)!}\).

\[\lim_{n\to\infty} \frac{a_{n+1}}{a_n} = \lim_{n\to\infty} \frac{(n+1)^3}{(2n+2)!} \cdot \frac{(2n)!}{n^3} = \lim_{n\to\infty} \left(1+\frac1n\right)^3 \cdot \frac{1}{(2n+2)(2n+1)} = 0 < 1\]

Karena limitnya \(0 < 1\), deret konvergen.

\[\boxed{\text{Konvergen}}\]

3.7 Integral Test (Divergen) Integral Test

Soal 3.7
\[\sum_{n=2}^{\infty} \frac{1}{n \ln n}\]
Penyelesaian

Gunakan Integral Test. Fungsi \(f(x) = \dfrac{1}{x \ln x}\) positif, kontinu, dan turun untuk \(x \ge 2\).

Substitusi \(u = \ln x\), \(du = \dfrac{dx}{x}\):

\[\int_2^{\infty} \frac{1}{x \ln x}\,dx = \lim_{t\to\infty} \int_{\ln 2}^{\ln t} \frac{du}{u} = \lim_{t\to\infty} \Big[ \ln|u| \Big]_{\ln 2}^{\ln t} = \lim_{t\to\infty} (\ln(\ln t) - \ln(\ln 2)) = \infty\]

Integral divergen, maka deret divergen.

\[\boxed{\text{Divergen}}\]
← Soal 3.6Soal 3.8 →
8

3.8 Integral Test (Konvergen) Integral Test

Soal 3.8
\[\sum_{n=2}^{\infty} \frac{1}{n(\ln n)^2}\]
Penyelesaian

Gunakan Integral Test. Fungsi \(f(x) = \dfrac{1}{x (\ln x)^2}\) positif, kontinu, dan turun untuk \(x \ge 2\).

Substitusi \(u = \ln x\), \(du = \dfrac{dx}{x}\):

\[\int_2^{\infty} \frac{1}{x (\ln x)^2}\,dx = \lim_{t\to\infty} \int_{\ln 2}^{\ln t} u^{-2}\,du = \lim_{t\to\infty} \Big[ -\frac{1}{u} \Big]_{\ln 2}^{\ln t} = \lim_{t\to\infty} \left(-\frac{1}{\ln t} + \frac{1}{\ln 2}\right) = \frac{1}{\ln 2}\]

Integral konvergen, maka deret konvergen.

\[\boxed{\text{Konvergen}}\]

3.9 Root Test Root Test

Soal 3.9
\[\sum_{n=1}^{\infty} \left(\frac{2n}{3n+1}\right)^n\]
Penyelesaian

Gunakan Root Test dengan \(a_n = \left(\dfrac{2n}{3n+1}\right)^n\).

\[\lim_{n\to\infty} \sqrt[n]{a_n} = \lim_{n\to\infty} \frac{2n}{3n+1} = \lim_{n\to\infty} \frac{2}{3 + 1/n} = \frac{2}{3} < 1\]

Karena limitnya \(2/3 < 1\), deret konvergen.

\[\boxed{\text{Konvergen}}\]

3.10 Direct Comparison Test Comparison Test

Soal 3.10
\[\sum_{n=1}^{\infty} \frac{1}{n^2 + n}\]
Penyelesaian

Bandingkan dengan \(\sum \dfrac{1}{n^2}\) yang konvergen (deret-p dengan \(p=2\)).

Untuk \(n \ge 1\): \(n^2 + n > n^2\) sehingga \(\dfrac{1}{n^2+n} < \dfrac{1}{n^2}\).

\[0 < \frac{1}{n^2+n} < \frac{1}{n^2}, \quad \sum \frac{1}{n^2} \text{ konvergen}\]

Berdasarkan Direct Comparison Test, deret konvergen.

\[\boxed{\text{Konvergen}}\]

3.11 Alternating Series AST

Soal 3.11
\[\sum_{n=1}^{\infty} (-1)^{n+1} \frac{n}{n^2+1}\]
Penyelesaian

Uji AST: \(b_n = \dfrac{n}{n^2+1}\).

\[\lim_{n\to\infty} b_n = \lim_{n\to\infty} \frac{n}{n^2+1} = 0\]

Untuk \(n \ge 2\), \(b_n\) monoton turun karena \(f'(x) = \dfrac{1-x^2}{(x^2+1)^2} < 0\) untuk \(x > 1\).

Berdasarkan AST, deret konvergen.

Konvergen mutlak/bersyarat: Uji \(\sum b_n = \sum \dfrac{n}{n^2+1}\). Bandingkan dengan \(\sum 1/n\) menggunakan LCT:

\[\lim_{n\to\infty} \frac{n/(n^2+1)}{1/n} = \lim_{n\to\infty} \frac{n^2}{n^2+1} = 1\]

Karena \(\sum 1/n\) divergen, \(\sum b_n\) divergen. Jadi deret konvergen bersyarat.

\[\boxed{\text{Konvergen bersyarat}}\]

3.12 Alternating Series AST

Soal 3.12
\[\sum_{n=1}^{\infty} (-1)^{n+1} \frac{n^4}{2^n}\]
Penyelesaian

Uji AST: \(b_n = \dfrac{n^4}{2^n}\).

\[\lim_{n\to\infty} b_n = \lim_{n\to\infty} \frac{n^4}{2^n} = 0 \quad (\text{eksponensial dominan})\]

Untuk \(n\) cukup besar, \(b_n\) monoton turun.

Berdasarkan AST, deret konvergen.

Konvergen mutlak: Uji \(\sum \dfrac{n^4}{2^n}\) dengan Ratio Test:

\[\lim_{n\to\infty} \frac{(n+1)^4/2^{n+1}}{n^4/2^n} = \lim_{n\to\infty} \left(1+\frac1n\right)^4 \cdot \frac12 = \frac12 < 1\]

\(\sum b_n\) konvergen, jadi deret konvergen mutlak.

\[\boxed{\text{Konvergen mutlak}}\]

3.13 Alternating Series AST

Soal 3.13
\[\sum_{n=1}^{\infty} (-1)^{n+1} \frac{n^2}{e^n}\]
Penyelesaian

Uji AST: \(b_n = \dfrac{n^2}{e^n}\).

\[\lim_{n\to\infty} b_n = \lim_{n\to\infty} \frac{n^2}{e^n} = 0\]

Untuk \(n\) cukup besar, \(b_n\) monoton turun. Berdasarkan AST, deret konvergen.

Konvergen mutlak: Uji \(\sum \dfrac{n^2}{e^n}\) dengan Ratio Test:

\[\lim_{n\to\infty} \frac{(n+1)^2/e^{n+1}}{n^2/e^n} = \lim_{n\to\infty} \left(1+\frac1n\right)^2 \cdot \frac1e = \frac1e < 1\]

\(\sum b_n\) konvergen, jadi deret konvergen mutlak.

\[\boxed{\text{Konvergen mutlak}}\]

3.14 Alternating Series (Akar Kompleks) AST

Soal 3.14
\[\sum_{n=2}^{\infty} (-1)^{n+1} \frac{1}{\sqrt{n^2-1}}\]
Penyelesaian

Uji AST: \(b_n = \dfrac{1}{\sqrt{n^2-1}}\).

\[\lim_{n\to\infty} b_n = \lim_{n\to\infty} \frac{1}{\sqrt{n^2-1}} = 0\]

\(b_n\) monoton turun karena penyebut \(\sqrt{n^2-1}\) naik. Berdasarkan AST, deret konvergen.

Konvergen mutlak/bersyarat: Uji \(\sum \dfrac{1}{\sqrt{n^2-1}}\). Bandingkan dengan \(\sum 1/n\) menggunakan LCT:

\[\lim_{n\to\infty} \frac{1/\sqrt{n^2-1}}{1/n} = \lim_{n\to\infty} \frac{n}{\sqrt{n^2-1}} = \lim_{n\to\infty} \frac{1}{\sqrt{1-1/n^2}} = 1\]

Karena \(\sum 1/n\) divergen, \(\sum b_n\) divergen. Jadi deret konvergen bersyarat.

\[\boxed{\text{Konvergen bersyarat}}\]

# Latihan Soal Kalkulus — UAS Preparation

Kumpulan 34 soal kalkulus dengan solusi lengkap langkah demi langkah, disajikan dalam format HTML interaktif.

## Struktur File

| File | Deskripsi | Jumlah Soal |
|------|-----------|:-----------:|
| `index.html` | Halaman navigasi hub + ringkasan coverage | — |
| `part1-integral-teknik.html` | Teknik Integral: substitusi, parsial, trigonometri, substitusi trigonometri | 11 |
| `part2-integral-aplikasi.html` | Aplikasi Integral: luas, panjang kurva, volume rotasi | 5 |
| `part3-deret-konvergen.html` | Kekonvergenan Deret Tak Hingga: Ratio, Integral, Root, Comparison, Alternating Test | 14 |
| `part4-deret-taylor.html` | Deret Taylor & Maclaurin: ekspansi fungsi akar, arctan, arccot | 3 |

## Fitur

- **MathJax** — render notasi kalkulus (LaTeX)
- **Dark mode** — toggle tema, tersimpan di localStorage
- **Navigasi** — antar-soal (prev/next) dan antar-part
- **Section completion** — checkbox di sidebar, tersimpan di localStorage
- **Responsive** — desktop dan mobile

## Cara Menggunakan

1. Buka `index.html` di browser
2. Klik salah satu part untuk memulai
3. Gunakan sidebar untuk lompat ke soal tertentu
4. Centang checkbox untuk menandai soal selesai
